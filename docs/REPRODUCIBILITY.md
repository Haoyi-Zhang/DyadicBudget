# Reproducibility and release verification

This artifact is self-contained and uses exact rational arithmetic from the Python standard library. It does not download data, call a model API, require a GPU, or depend on a package registry.

## Supported runtime

- CPython 3.10 or newer.
- A POSIX-like shell is convenient for the expanded command list, but the one-command driver itself is Python.
- The retained validation was executed with one worker and deterministic seeds.

## One-command scientific replay

```bash
export PYTHONHASHSEED=0
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
python run_all.py
```

`run_all.py` returns nonzero on any failed unit test, oracle comparison, certificate replay, timeout, or deterministic-result comparison. The explicit commands remain documented in the main README and status records.

## Distribution integrity

```bash
python verify_release.py --integrity-only
python verify_release.py --run
```

The first command verifies the immutable-file manifest, path safety, required files, Python syntax, and absence of packaged caches. The second performs those checks and then runs the full scientific replay. The manifest deliberately excludes generated result files, logs, bytecode caches, and the manifest itself; those outputs may be regenerated by the replay.

## Evidence boundary

The executable checks support the implementation and the finite validation claims. They are not a proof-assistant certification of the general mathematical theorems. The paper supplies the written proofs and states the frozen semantic assumptions and exclusions.
