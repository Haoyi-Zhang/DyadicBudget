# Licensing boundary

No third-party solver, benchmark implementation, model, or scholarly PDF is
bundled in this repository. The implementation and generated finite inputs are
covered by the repository license. The five published factual weight rows are
attributed separately; no source-paper prose, figures, or PDF is redistributed.
The paper-side ACM class and bibliography style, when present in the larger
project, keep their supplied upstream license and are not part of this
standalone repository.
